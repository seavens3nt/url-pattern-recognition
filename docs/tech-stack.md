# Tech Stack

| Area | Technology | Purpose |
| --- | --- | --- |
| Frontend | React + Vite | Build the URL input form, validation results, and interactive state transition display. |
| Styling | CSS | Create responsive layouts and consistent visual styles. |
| UI/UX Design | Figma | Design wireframes and user interactions. |
| Backend / API | Python + Flask | Receive URLs from React and return validation results. |
| Automata Logic | Custom Python modules | Implement the NFA, DFA, minimization, and DFA simulator. |
| Diagrams | Graphviz | Generate NFA, DFA, and minimized DFA diagrams. |
| Testing | pytest; Vitest + React Testing Library | Test backend logic, API endpoints, and frontend interactions. |
| Collaboration | Git + GitHub | Manage source code, tasks, and contributions. |
